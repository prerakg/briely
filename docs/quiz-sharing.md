# Creating and sharing quizzes

1. Open a study material and press Create Quiz, or open Quiz Studio, choose a local source and press Create Quiz. Defaults are 10 mixed-difficulty single-answer questions. Advanced options support counts, difficulty and single/multiple/true-false/mixed types. Original text, recorded/YouTube transcripts, summaries and notes can supply the source.
2. Review the editable draft. Edit questions/options/keys/explanations, add/delete/reorder or regenerate an individual question with a selected source. A separate AI review runs before generated questions are accepted. You can also write a manual quiz without an AI key or import an existing local practice quiz.
3. Set time limit, attempts per browser, shuffle, feedback visibility, expiration, access and optional public leaderboard. Save draft or preview the participant view.
4. Publish & Share creates a new immutable database snapshot and a 192-bit random share token. Copy the link. Private quizzes also return an invitation code; save and share it separately. Only the hash is stored, so the code cannot be recovered later. Republishing creates a new snapshot/link. Unpublish disables every published version while preserving attempts.
5. A guest opens `/quiz/:shareId`, enters a name and starts without an account. Questions/options are sanitized before returning. Explanations, exact source quotes and answer indices are excluded before submission. Display names are not verified identities.
6. The guest answers and submits. Backend exact-set grading handles multiple answers without partial credit. Timers use server deadlines; submissions have a two-second transport grace. Late submissions receive no credit. Refresh restores the active attempt and locally selected answers in that tab. A submitted attempt can be replayed only with the same answers; different answers return 409.
7. Results show score, percentage, time and weak topics; explanations follow publication settings. Creator Analytics shows attempts, distribution, hardest questions, topic accuracy and paginated recent attempts. The public leaderboard endpoint is available only when the creator opted in. Personal AI study plans are generated from aggregate quiz statistics in Study Planner.

Anonymous limits apply to the guest browser cookie, not a verified person. A guest can evade them by clearing cookies/changing devices. Private invitation codes are transferable and represent possession-based access, not individually verified invitees. Quiz links do not authorize access to private source documents.

Links work across devices only when both can reach the same running backend/frontend origin. `localhost` refers to each device itself. Set `FRONTEND_URL` to a reachable origin for LAN testing or use a proper HTTPS deployment. Direct production links are served by the backend SPA fallback.
